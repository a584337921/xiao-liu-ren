# 小六壬起课计算器

一个基于传统小六壬掌诀的在线起课工具，支持按农历月、日、时辰推算六神落宫，并根据不同事类给出针对性占断解读。

## 功能特点

- **传统算法**：严格遵循"大安起正月，月上起日，日上起时"的掌诀推算规则
- **可视化掌诀图**：左侧实时显示左手三指六神位置，推算过程动态高亮
- **分步动画**：月起 → 日起 → 时起，每步展示推算路径
- **事类占断**：支持求财、寻物、寻人、出行、疾病、婚姻、官事等针对性解读
- **问事备注**：可记录具体问题，方便后续对照
- **一键取时**：自动获取当前公历时间并转换为时辰

| 小吉 | 小吉最吉昌，路上好商量，阴人来报喜，失物在坤方 |

## 本地使用

直接用浏览器打开 `index.html` 即可，无需任何服务器或依赖。

## 部署到 GitHub Pages

1. Fork 或新建一个 GitHub 仓库
2. 将 `index.html` 上传到仓库根目录
3. 进入仓库 Settings → Pages
4. Source 选择 "Deploy from a branch"，分支选 `main`，文件夹选 `/ (root)`
5. 保存后等待 1-2 分钟，访问 `https://你的用户名.github.io/仓库名/` 即可使用

## 技术说明

- 纯前端实现，HTML + CSS + JavaScript，无后端依赖
- 响应式设计，支持手机和桌面端访问
- 所有数据均在本地计算，不收集任何用户信息
