# 小六壬起课计算器

基于传统小六壬掌诀的在线起课工具。输入公历日期，自动转换为农历月、日、时辰，推算六神落宫，并根据所选事类给出详细占断解读。

## 功能特点

- **公历转农历**：输入公历日期自动转换，起课使用农历月日时，支持 1900-2100 年
- **传统算法**：严格遵循"大安起正月，月上起日，日上起时"的掌诀推算规则
- **详细解卦**：六神（青龙/玄武/朱雀/白虎/六合/勾陈）、五行、方位、吉数、传统口诀
- **八种事类**：一般占断、求财、寻物、寻人、出行、疾病、婚姻、官事，每类 2-3 段详细分析
- **可视化掌诀图**：左侧实时显示左手三指六神位置，推算过程动态高亮
- **分步动画**：月起 → 日起 → 时起，每步展示推算路径
- **问事备注**：可自由填写具体问题，方便对照结果
- **一键取时**：自动获取当前公历时间并转换为农历和时辰

## 技术说明

- 纯前端实现，HTML + CSS + JavaScript，无后端依赖
- 内置 1900-2100 年农历数据，公历转农历无需联网
- 响应式设计，支持手机和桌面端访问
- 所有数据均在本地计算，不收集任何用户信息
